## Hoe draai je en test je het project?

### Vereisten (Prerequisites)

Voer uit in de terminal: "npm install"

Je moet voor het draaien van het project Node v22.22.2 hebben

### Draaien

Voer uit in de terminal: "npx tsx src/server.ts"

Hij draait op localhost:3000

### Testen

Voer uit in de terminal: "npx vitest run"
